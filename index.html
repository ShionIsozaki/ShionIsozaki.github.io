体を動かして学ぶことができる天体の学習支援システム

ここに研究のデモ動画（assets/research-demo.mp4）

宇宙船脱出ゲーム研究・開発中

Unity 6 ／ 2画面構成（壁スクリーン＋床面投影）／ 2D LiDAR による立ち位置操作

児童が興味を持ちにくいとされる小学校理科の天体単元に関して、体を動かしながら学べることを目指した学習支援システム。

宇宙船に迷い込んだ主人公が、天体にまつわるギミックをクリアしながら地球への帰還を目指す3Dアクションアドベンチャー。プレイヤーは床に立つ位置を左右に移動したり、ジャンプしたりすることでキャラクターを操作する。

技術
Unity / C#、SLAMTEC RPLIDAR A1、Python（センサー読み取り → UDP で Unity へ送信）
工夫
ゲームとしての没入感を高めるため、天体と無関係のアクションギミックを用意し、さらに足が検出されなくなった瞬間をジャンプとして判定させることで動作のバリエーションを増やし、操作が単調になりにくいようにした。

Quiz Adventure

OpenFrameWorks ／ C++ ／ アドベンチャー

次々と出題される二択クイズに立ち位置で回答し、クリアを目指すゲーム。未就学児、小学1~6年、中学生以上の8パターンから出題されるクイズの難易度を選択でき、さらに科目も選べる。収録された問題数は600問以上。地域の科学館で展示を行った。

実装
Webカメラ、ノイズ抑制、背景差分法
工夫
テレビ番組の企画をオマージュしたもので、これを学習支援に生かせないかと考え、このような形になった。膨大な問題数を用意したため、どのプレイヤーにも適切な難易度の問題を出題することができた。
ここにデモ動画（assets/game4-demo.mp4）

ORBIT SLING ／ GRAVITY MERGE ／ STAR LINE

Claude Code, Node.js ／ TypeScript, Phaser ／ ミニゲーム

天体に関する要素を取り入れた、ミニゲーム集。生成AIでのアプリ開発に興味を持ち、研究のアイデアを得ることを目的として制作した。ORBIT SLINGはタイミングよく探査機を打ち出してハイスコアを目指す。GRAVITY MERGEは天体同士を合わせて大きな天体を作っていき、ハイスコアを目指す。STAR LINEはランダムに生成される星の配置から一筆書きできる経路を探すゲームで、実在する星座をなぞって体験するモードも収録。

ここにデモ動画（assets/game5-demo.mp4）

RING SORT ／ SOLAR RELAY ／ ORBIT HOP

Claude Code, Node.js ／ TypeScript, Phaser ／ ミニゲーム

RING SORTは色ごとに軸を分ける脳トレゲームで、レベルが上がるとリングの数が増える。SOLAR RELAYは光源から発せられた光を屈折させて、正しい経路に導くゲーム。高レベルになるとプリズムやワープといった要素が追加される。ORBIT HOPは惑星の周囲を回っている探査機を、タイミングよく発射するゲーム。コインをためると新たなスキンを解放できる。

おえかきバランスゲーム

Unity ／ C# ／ 物理パズル

プレイヤー同士が画面上に自由な線を描き足し、それがそのまま物理法則に従う物体となって積み重なっていく対戦型お絵描きバランスゲームです。タワーを崩してしまったプレイヤーが負けとなります。

実装
物理演算、シーン管理、動的コライダー生成、タイマー管理など
工夫
決められた形状のブロックを積み重ねるのではなく、自身で自由な図形を落とすことができるようになっている点。これにより戦略の幅が広がり、楽しみ方のレパートリーも増えた。

価格検索・比較ソフト個人開発

Python ／ Yahoo!ショッピングAPI ／ 価格比較アプリ

品物の名称を検索欄に入力すると、そのキーワードを含むYahooショッピング上に掲載された商品の価格や在庫、商品ページのURLなどが表示され比較できるようになっている。これはYahoo社が無料で提供している商品検索APIを用いて実装した。開発のきっかけは、アルバイト中に聞こえたお客様の会話内容からアイデアを得たことである。

工夫
ニーズを考慮しできるだけシンプルなUIにし、ファイル出力できるようにした。また、税込み価格と実質合計価格を並べて表示することで、買い手が実際に支払う料金を一目で分かるようにした。

MEPAT授業実習

ICTソリューション実践 ／ React Native ／ チーム開発（5人)

自宅にある食材の在庫管理をサポートするモバイルアプリ。「バーコード読み取り」「レシート読み取り」「冷蔵庫内撮影」「手動入力」の4つの方法で食材とその賞味、消費期限を登録することができる。期限が近づいてくると自動でその食材を使った献立を提案する。
